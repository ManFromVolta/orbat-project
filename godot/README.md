# ORBAT: кукла, анимации, движение

Прототип под Godot 4.7: кукла человека на скелете по контракту, клипы idle/walk/run, контроллер от третьего лица с камерой через плечо, тестовая арена и headless-тесты.

## Запуск

Открыть папку `godot/` в Godot 4.7, F5.

| Ввод | Действие |
|---|---|
| WASD | движение относительно камеры |
| Shift | бег |
| Мышь | камера |
| Esc / ЛКМ | отпустить / захватить курсор |

## Структура

| Путь | Что |
|---|---|
| `mannequin/skeleton_spec.gd` | Контракт скелета: кости, иерархия, пропорции |
| `mannequin/mannequin.tscn` | Кукла: `Skeleton3D`, части на `BoneAttachment3D`, `AnimationPlayer`, `AnimationTree` |
| `mannequin/mannequin.gd` | Интерфейс куклы наружу: `set_speed(м/с)` |
| `mannequin/locomotion.tres` | Библиотека клипов idle, walk, run |
| `player/player.gd`, `player.tscn` | `CharacterBody3D`, камера `SpringArm3D` с плечевым смещением |
| `scenes/test_arena.tscn` | Плоская арена с шахматкой 1×1 м и препятствиями |
| `tools/` | Генераторы ресурсов и скрипты снимков |
| `tests/run_tests.gd` | Headless-тесты |

## Контракт скелета

- Имена костей, иерархия и ориентация осей: `SkeletonProfileHumanoid` движка. Любые гуманоидные анимации ретаргетятся через `BoneMap` без правок.
- T-поза в покое, модель смотрит в **+Z** (как в glTF), левая сторона = **+X**, ось Y кости идёт вдоль кости к дочерней.
- 1 ед. = 1 м, рост 1.75 м, сустав стопы на 0.09 м над землёй (подошва = 0).
- Все 17 обязательных костей профиля есть. Пальцев, глаз и челюсти пока нет.
- Игрок стоит в сцене с `Model.rotation.y = PI`, то есть лицом в -Z, от камеры.

Изменить пропорции или набор костей: правь `skeleton_spec.gd` и пересобери (ниже).

## Сгенерированные файлы

`mannequin.tscn`, `locomotion.tres`, `player.tscn` и `test_arena.tscn` собирает скрипт:

```
godot --headless --path godot -s tools/build_all.gd
```

Он **перезаписывает** эти файлы. Если начнёшь править сцену в редакторе руками, убери соответствующий шаг из `tools/build_all.gd`.

## Тесты

```
godot --headless --path godot -s tests/run_tests.gd
```

Код выхода 0 = всё прошло. Проверяется: скелет против профиля движка, рост, T-поза и направление взгляда; шов цикла клипов; колени и локти не гнутся назад; ноги в противофазе, руки в противофазе с одноимённой ногой; стопа не уходит под землю; дерево анимации по скорости; игрок на арене (ходьба 1.4 м/с, бег 4.5 м/с, остановка).

Снимки поз и арены (нужен рендер, например xvfb): `tools/shot.gd`, `tools/shot_arena.gd`, команды в шапках скриптов.

## Ограничения

- Клипы процедурные, это заглушка до настоящих анимаций из Blender или mocap. Скелет и дерево под них готовы.
- IK стоп нет. Таз подгоняется по вертикали, но стопа скользит по земле: по тестам стояночная стопа едет назад со скоростью около 90% скорости тела при ходьбе и около 71% при беге.
- В беге есть фаза полёта: в 40% кадров обе стопы над землёй.
- Кукла собрана из жёстких примитивов на `BoneAttachment3D`, это не скин-меш.
- Ходьба и бег только по прямой: нет стрейфа, приседа, поворота на месте, оружия, предметов, лошади.
